# Referencias para el rediseño del chat

Consulté interfaces y guías oficiales de productos de comunicación para definir patrones concretos, no para calcar una marca.

## Discord

[Actualización de escritorio de Discord, 25 de marzo de 2025](https://discord.com/blog/discord-update-march-25-2025-changelog)

- La interfaz ofrece temas y densidades distintas; eso confirma que el espaciado y la cantidad de información visibles son parte del diseño del producto.
- Los controles de voz se agrupan en una barra; el prototipo usa una barra de llamada persistente sobre el compositor.
- Las listas pueden cambiar de tamaño; el prototipo mantiene separadas la navegación, las conversaciones y el chat para que cada zona tenga una función clara.

## Slack

[Entender los mensajes directos en Slack](https://slack.com/help/articles/212281468-Understand-direct-messages)

- Los mensajes directos tienen una vista propia, búsqueda de conversaciones y una acción clara para iniciar un mensaje.
- El prototipo conserva la lista dedicada de conversaciones y la búsqueda, reducidas al alcance del MVP.

[Un Slack rediseñado para concentrarse](https://slack.com/blog/productivity/a-redesigned-slack-built-for-focus)

- La reorganización del acceso a mensajes, actividad y conversaciones informa la separación entre la navegación principal y la lista de mensajes directos.

## Decisiones para ENTRE

- Se conserva la estructura de aplicación social: barra de navegación, lista de conversaciones y conversación activa.
- La pantalla muestra actividad realista —mensajes agrupados, horas, presencia, selección y llamada conectada— para que el espacio no parezca una plantilla vacía.
- La identidad es propia: grafito azulado, verde cítrico y coral para terminar llamada; no usa la marca ni el morado de Discord.
- El panel de llamada queda junto al chat para seguir escribiendo y controlar el micrófono sin salir de la conversación.
- Los nombres, mensajes, avatares y estados son datos ficticios de la maqueta.
