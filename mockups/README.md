# Mockups

## Versión actual

- `chat-v2.html`: prototipo de interfaz navegable sin backend; permite cambiar de conversación, buscar personas, escribir mensajes de muestra y alternar estados de llamada.
- `04-chat-v2.png`: conversación con llamada activa, escritorio 1440 × 900.
- `05-chat-sin-llamada-v2.png`: conversación después de finalizar la llamada.
- `06-mobile-v2.png`: vista móvil 390 × 844.
- `07-mobile-contactos-v2.png`: lista de personas abierta en móvil.
- `08-chat-v2-1536.png`: vista de escritorio al tamaño del concepto visual, 1536 × 1024.
- `assets/avatars/`: retratos ilustrados ficticios usados por el prototipo.
- `assets/concept-chat-v2.png`: concepto visual usado como referencia durante el rediseño.

La interfaz no registra usuarios ni mensajes, y no captura audio. Las acciones de mensajes y llamadas solo muestran estados locales de maqueta.

## Versión anterior

`01-mensajes.png`, `02-llamada.png` y `03-registro.png` son la primera propuesta, rechazada por verse demasiado genérica. Se conservan para dejar visible el cambio de dirección.

Las fuentes y decisiones del rediseño están en [REFERENCIAS-DISENO.md](../docs/REFERENCIAS-DISENO.md).
